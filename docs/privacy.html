BI Analytics GPT Privacy Policy

This GPT supports BI analytics workflows, including generating dashboard assets, metadata, semantic-layer files, documentation, and GitHub pull requests.

Data processed

The GPT may process user prompts, uploaded or referenced sample data, generated dashboard files, metadata, semantic-layer definitions, repository names, branch names, commit messages, and pull request descriptions.

Purpose

Data is used only to complete requested BI analytics tasks, such as creating, updating, reviewing, or documenting files and opening pull requests in connected repositories.

Storage

Generated files may be stored in the connected GitHub repository. Users should not provide passwords, API keys, private keys, access tokens, production secrets, or other sensitive credentials.

Third-party services

This GPT may interact with GitHub or configured backend services to perform repository operations requested by the user.

User responsibility

Users are responsible for reviewing generated files, pull requests, and any data they choose to provide before merging or publishing changes.

Contact

For privacy questions, contact the repository owner.
