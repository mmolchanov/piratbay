# BI Analytics Repository

This repository stores BI Analytics assets used by GPT-assisted dashboard generation workflows.

## Main folders

- `data/sample/` — sample CSV files for development and GPT context.
- `metadata/` — human-readable table and column descriptions.
- `semantic/` — business dimensions, measures, and metric logic.
- `dashboards/` — dashboard templates and layout rules.
- `prompts/` — reusable GPT instructions and generation prompts.
- `validation/` — checklists and rules for reviewing generated outputs.
- `docs/` — workflow and architecture documentation.

## Workflow

Create changes on a feature branch, open a pull request into `main`, and review generated files before merging.
