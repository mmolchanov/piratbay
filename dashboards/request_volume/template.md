# Request Volume Dashboard Template

## Filters

- Start Date: dynamic default based on current date.
- End Date: dynamic default based on current date.
- Business
- Region
- Desk
- Sub Desk
- Analyst
- Manager
- Salesperson
- Desk Location
- Request Type
- Cash vs Derivative

## KPI cards

- Received Requests
- Completed Requests
- In Progress Requests
- On Hold Requests

## Visual sections

### Request Volume Trend
Show received and completed request counts over time.

### Request Status Breakdown
Show request counts by status.

### Workload by Analyst and Manager
Show request volume by analyst and manager.

### Desk and Region Analysis
Show request volume by desk, sub-desk, region, and city-level desk location.

## Excluded sections

Do not include Cycle Times.
Do not include Cancelations section.
